# React AV starter

[Open in StackBlitz](https://stackblitz.com/github/Wykerd/react-av/tree/master/examples/starter)

Or run locally:

```sh
npm install
npm run dev
```

Edit `src/main.tsx` to compose your player and `src/style.css` to style it. Replace `public/clip.webm` with your own media.

This example uses the published React AV packages with React 18.3, which their current peer dependencies support. It installs independently of the repository's pnpm workspace.
