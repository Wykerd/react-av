# WebVTT file parsing fixtures

The `.vtt` files are copied byte-for-byte from [web-platform-tests](https://github.com/web-platform-tests/wpt/tree/561228c9c38619665d9956c74086c45ec4960e9c/webvtt/parsing/file-parsing) (`webvtt/parsing/file-parsing`). `expected-cues.json` lists, per fixture, the cue properties asserted by the matching WPT test, with cue regions compared by region id rather than by object identity.

Both are covered by the web-platform-tests BSD 3-Clause licence in [LICENSE.md](./LICENSE.md).
